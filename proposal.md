## Description
A simple turn based game where the player fights enemies leading up to a final boss

## Features
- Turn-based combat
	- give player combat choices every turn, then execute both player's and enemy's turn after input.
- Animated sprites for player and enemies
	- Calculate which frames the sprite should change, and play animation using the calculation
- Dodging mechanic
	- Give player a window of time where they can press a key. If successful, enemy deals less/no damage

## Challenges
- Implementing user input with on screen buttons
- Creating animated sprites
- Drawing different shapes and letters to the screen

## Outcomes
Ideal Outcome:
- Turn based rpg with fully animated sprites, limited items, and dialogue system

Minimal Viable Outcome:
- Simple turn based combat with sprites, basic dodging mechanic, and unlimited items
